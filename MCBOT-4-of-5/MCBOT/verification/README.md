# 動作確認用ファイル

`npm test` でこのフォルダの自動チェックを実行できます。

| フォルダ | 確認する内容 |
|---|---|
| connection | ログイン、接続、パケット、地形の読み込み |
| combat | 戦闘とMobAura |
| mining | 採掘、床、足場、Nuke |
| movement | 移動、通路、段差 |
| inventory | 装備、補給、アイテム |
| interfaces | Web、Discord、Desktop、チャット |
| runtime | Botの実行とログ |
| regression | バージョンごとの修正をまとめた確認 |
| helpers | チェックで使う共通の補助コード |
