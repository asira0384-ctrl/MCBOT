# Asira Clear Bot v0.3.13

Minecraft統合版のBotをDiscordとWebから操作する、既存MCBOTサービス用の更新版です。

**更新手順は [UPDATE-v0.3.13-JA.md](UPDATE-v0.3.13-JA.md) を開いてください。** ZIPを解凍し、AsiraClearBotフォルダの中身をGitHubの既存ファイルへ上書きします。Railwayのデプロイ成功後、WebをCtrl+F5で再読み込みします。Variablesと保存済みdataは引き継いでください。

## v0.3.13の変更

- 所持品の更新順序・個数0の処理、即時のWeb反映と確認中の表示。
- Totem発動時の操作キャンセルと補充優先度、KA・CAの送信待機、PAの方向と停止からの復帰、Jetpackの継続条件を修正。
- FeetTrapは自分のホールを作成・探索。IGNではPvP中に自己ホールを自動化し、AntiCrystalを無効化。
- Bot番号を変えず接続先を変更でき、IGNに移したBotでもWorld・Kit・TPA・Backを使用。
- 金ハート表示、AutoLogのショートカットと金ハートの判定設定、5つのテーマ。
- チャットとtellの認証情報・送信状態・受信拒否の表示、原子的な認証キャッシュの保存と復旧。

324件成功。詳細は [検証記録](VALIDATION-v0.3.13.md)。

- Microsoftのコードコピー、認証成功時の画面の自動閉じ、アカウントに固定した認証キャッシュと旧形式の移行。
- 暗号化バックアップと復元。敵・フレンド・認証・設定を新しいサービスへ移せます。
- 太字を減らしたWeb、ユーザーごとの壁紙・操作音・通知音。
- IGN専用のKit・TPA・Back、足跡を記憶するプレイヤー追従、AutoLogの条件選択。
- 剣と設置物の枠競合、防具のサーバー更新、複数スタックの補充、無差別攻撃の表示を修正。
- Legacy/NukkitのPA方向と押し込み未対応時の処理、Anti設定中のJetpackの発動判定を修正。

v0.3.12時点の検証は304件成功。[検証範囲](VALIDATION-v0.3.12.md)を参照してください。

## v0.3.11までの修正

- PA中はKA・CA・FeetTrap・追尾による視点変更を待機。ピストン方向の送信とサーバー側の向きを確認し、足場→ピストン→Crystal→電源→押し込み→起爆を進めます。
- Nukkitなどでピストンの向きが反転する場合、受信した方向から方式を学習して保存し、自分の逆向きピストンを回収して再試行します。回収用ピッケルが必要です。
- KAは剣を選択した直後の競合を防ぎ、攻撃前にインベントリ画面を閉じます。移動中の別スロットの確認は継続します。
- 戦闘中は位置補正・追尾停止・食事を理由にAntiを解除しません。サーバー位置に基づいて足場の基準を更新し、視点と移動入力を一致させます。
- プレイヤーの座標基準をパケット別・プレイヤー別に保持。Antiで埋まった敵へのCAも、有効な露出と設置面を評価します。
- 食事中の同じスロットへの装備再送を防止。手が空いた直後に回復を開始し、サーバーの使用状態・消費・効果を確認します。
- 戦闘で使っているスタックをAutoSlotから保護し、PAの途中で配置用アイテムが入れ替わる競合を抑制。
- レポートに標的位置・座標基準・PAの足場段階・戦闘中のAnti保護を追加。

以下のv0.3.10の修正も含みます。

- 設置・持ち替えの競合、FeetTrapの待ち時間、KAの剣の選択を修正。

- ブロック参照をキャッシュし経路探索を改善。無差別攻撃の設定名とPvP OFFも修正。

Node.js 24用です。Discordの操作は設定された本人だけが使えます。ゲーム内の座標確認は誰でも使え、操作管理者の登録はDiscordから行います。

既定ではBot1〜10が2b2e用のAslrq01x〜Aslrq10x、Bot11がIGN用のAslrq00xです。Bot11にはIGN_HOST・IGN_PORTを設定してください。認証したゲーマータグは設定と一致する必要があります。

認証・設定はDATA_DIRへ保存します。RailwayではMCBOTにVolumeを接続し、Mount PathとDATA_DIRを両方 /data にします。Volumeなしの再デプロイでは認証を引き継げません。認証情報を含むdataや.envはGitHubへアップロードしないでください。
