# Nuke 7.7

## 操作

1. BotまたはAll Botsを選択し、World → Nukeを右クリックします。
2. Start X/Y/ZとEnd X/Y/Zへ、採掘範囲の2つの角を指定します。
3. Nukeを左クリックして開始します。範囲の上下端を含め、高いYから採掘します。

座標の大小が逆でも自動で並べ替えます。同じYを指定すると1段だけ掘ります。
入力範囲はX/Zが±30000000、Yが-64〜319、範囲全体が1024チャンク以内です。
ディメンションに存在しない高さは実際のワールド上限に従います。

| 設定 | 内容 |
| --- | --- |
| Range | 採掘射程。1〜6ブロック |
| Blocks | 対象ブロックIDをカンマ区切りで指定。allですべて |
| Scaffold | 採掘への移動に必要な足場の自動設置 |
| Scaffold Block | 持ち物から使う足場のブロックID |
| Max Drop | 経路探索で許可する最大の落下距離 |

Nuke内の状態表示で未接続、地形受信待ち、ピッケル不足などを確認できます。
設定欄が長い場合はパネル内でスクロールしてください。

## 修正した動作

旧GUIは保存時にarea/floor/ceilingコマンドを順に実行して採掘を停止していました。
`src/model/world/nuke.js`で範囲を検証し、一括更新して実行中の採掘を再開します。
Rangeなどだけの変更では停止しません。旧チャンク指定は新しい範囲の保存時に解除します。
ピッケル不足や地形未受信など、開始できない条件はエラーとして表示します。

未受信の列があるだけで同じ高さの受信済みブロックまで待機していた処理も修正しました。
未受信部分を掘った扱いにはせず、下段へ進む前にその地形を待ちます。

内部のfloorは既存採掘エンジンとの互換性のため「下端Y-1」で保存します。
新GUIではこの内部表現を表示せず、Start/Endの座標へ変換します。
Scaffoldの旧APIは互換用に残し、新EXEでは単独のScaffold行を表示しません。

## 日本語説明

`desktop-native/descriptions-ja.h`にモジュール72件と設定152件の説明を配置しました。
設定名の上にカーソルを合わせても、その項目の説明を表示します。
日本語の表示にはSegoe UIを使い、通常のGUIフォント選択とは独立させています。
新しい設定はこの説明ファイルにも項目を追加してください。
