Toggle Sounds — MP3 + WAV

11種類、各ON/OFF、MP3とWAVを同梱。音声ファイルは合計44個。

例:
sound/sigma/sigma_on.mp3
sound/sigma/sigma_off.mp3
sound/sigma/sigma_on.wav
sound/sigma/sigma_off.wav

WAV: 44.1 kHz / 16-bit PCM / stereo
MP3: 前回渡した音源と同じ内容。
WAVは保存済みの原音から変換し、前回のMP3と同じピッチと音量に設定。
PistonはON/OFFで同じ音です。
